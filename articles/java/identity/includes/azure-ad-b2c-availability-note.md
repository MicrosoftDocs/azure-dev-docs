> [!NOTE]
> As of May 1, 2025, Azure Active Directory B2C is no longer available to purchase for new customers. Existing customers can continue to use Azure AD B2C, with support provided until at least May 2030. For new customer identity and access management (CIAM) projects, use [Microsoft Entra External ID](/entra/external-id/customers/overview-customers-ciam) instead.
